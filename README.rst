RPC
=======
The RPC (aka **R**emote **P**rocedure **C**all) library implements a simple, yet powerfull, RPC mechanism to be used on-top of i.e. CSP.

Features
--------
The RPC library can be used by both ARM based satellite modules and x86 based systems (i.e. CSH). It exposes a simple API for the user to be able to implement both the Server and the Client side of the RP mechanism.
